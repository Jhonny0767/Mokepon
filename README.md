# 🐾 MOKEPON! 🔥💧🌱

Juego multijugador de mascotas desarrollado como proyecto práctico del curso de Programación Básica de Platzi.

## 🚀 Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Canvas API para el mapa).
- **Backend:** Node.js, Express (para la comunicación de jugadores en tiempo real).
- **Herramientas:** Git, NPM.

## ✨ Características

- **Selección de Mascota:** Elige entre Hipodoge, Capipepo o Ratigueya.
- **Mapa Interactivo:** Movimiento fluido por un mapa usando las teclas de flecha.
- **Multijugador Básico:** Conexión a un servidor local para ver a otros jugadores en el mapa.
- **Sistema de Combate:** Detección de colisiones para iniciar batallas y sistema de ataques por turnos (Fuego, Agua, Tierra).
- **Lógica de Red:** Sincronización de coordenadas (X, Y) mediante Fetch API.
